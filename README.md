# Steal a Brainrot Online 🎮

A 3D multiplayer online tycoon game where you collect Brainrots, earn money, and climb the ranks!

## Features

✨ **3D Gameplay** - Explore your base with Three.js
💰 **Economy System** - Collect money and invest in Brainrots
🧬 **Brainrot Collection** - 6 rarity levels from Common to OG
🔄 **Rebirth System** - Unlock new slots and upgrades
🏆 **Leaderboard** - Compete with other players
⚙️ **Admin Panel** - Owner controls
👥 **Multiplayer** - Real-time interactions with Socket.IO

## Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up MongoDB locally or use a cloud instance
4. Create `.env` file from `.env.example`
5. Start server: `npm start` or `npm run dev`
6. Open `http://localhost:3000` in your browser
